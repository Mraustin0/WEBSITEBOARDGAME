# รูปภาพบรรยากาศร้าน (client/public/images)

หน้าเว็บจะโหลดรูปจากโฟลเดอร์นี้ผ่าน URL `/images/<ชื่อไฟล์>`
**ถ้ายังไม่มีไฟล์ หน้าเว็บจะแสดงภาพประกอบ (โต๊ะบอร์ดเกมแบบวาด) แทนโดยอัตโนมัติ** — ไม่มีรูปแตก
พอวางไฟล์ชื่อตรงตามตารางนี้ รูปจริงจะขึ้นแทนทันที (ไม่ต้องแก้โค้ด)

| ไฟล์         | ใช้ที่                                 | สัดส่วนแนะนำ | ขนาดแนะนำ (px) |
| ------------ | -------------------------------------- | ------------ | -------------- |
| `hero.jpg`   | หน้าแรก — รูปใหญ่ในส่วนหัว (โพลารอยด์) | 4:3          | 1600 × 1200    |
| `play-1.jpg` | หน้าแรก — ส่วนหัว + แกลเลอรีบรรยากาศ   | 1:1 หรือ 4:3 | 1200 × 1200    |
| `play-2.jpg` | หน้าแรก — ส่วนหัว + แกลเลอรีบรรยากาศ   | 1:1 หรือ 4:3 | 1200 × 1200    |
| `play-3.jpg` | หน้าแรก — แกลเลอรีบรรยากาศ             | 1:1          | 1200 × 1200    |
| `play-4.jpg` | หน้าแรก — แกลเลอรีบรรยากาศ             | 1:1          | 1200 × 1200    |
| `signin.jpg` | หน้าเข้าสู่ระบบ — แผงซ้าย (จอใหญ่)     | 16:10        | 1600 × 1000    |

รูปจะถูกครอปให้พอดีกรอบ (`object-cover`) จึงควรวางจุดสนใจ (คน / โต๊ะเกม) ไว้กลางภาพ

## คำแนะนำ

- ใช้ไฟล์ `.jpg` บีบอัดให้ไม่เกิน ~300 KB ต่อรูป (เช่น ผ่าน [Squoosh](https://squoosh.app) คุณภาพ 70–80)
- โทนภาพอบอุ่น แสงไฟเหลือง ๆ เข้ากับสีแบรนด์ (เขียวเข้ม / ครีม / แดงอิฐ / มัสตาร์ด)
- เนื้อหา: กลุ่มเพื่อนหรือครอบครัวกำลังเล่นบอร์ดเกม หัวเราะ ลุ้นตาสุดท้าย, มือที่กำลังทอยเต๋า/วางการ์ด, ชั้นวางเกมในร้าน
- ดีที่สุดคือ **รูปจริงจากร้าน** (ขออนุญาตลูกค้าที่อยู่ในภาพก่อนนำมาใช้)
